## 📱 About The Project

**Mahva Shop** is a Flutter-based e-commerce application designed to provide a clean, modern, and visually appealing shopping experience.

The project focuses on creating a structured shopping interface with product showcases, product details, portfolio sections, splash screen, and reusable UI components.

It was developed using **Flutter & Dart**, with a focus on clean UI implementation, responsive layouts, reusable widgets, and a smooth user experience.

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/MobinaFetrati/mahva-shop.git
```

### 2️⃣ Navigate to the project

```bash
cd mahva-shop
```

### 3️⃣ Install dependencies

```bash
flutter pub get
```

### 4️⃣ Run the application

```bash
flutter run
```

---

## 📦 Build

To create a release APK:

```bash
flutter build apk --release
```

For a Windows build:

```bash
flutter build windows
```
